# ClipAssist

[English](README.md) | **简体中文**

ClipAssist 是一款面向 Windows 11 的轻量级剪贴板历史管理工具，使用 C#、WPF 和 .NET 开发，旨在让剪贴板历史的查看、搜索和管理更加方便。

## 项目状态

ClipAssist 目前正在积极开发中。随着项目不断完善，功能和使用方式可能会发生变化。

## 功能特性

- **剪贴板历史记录** — 自动记录近期复制的文本内容，方便随时查看和复用。
- **快速搜索** — 支持对剪贴板历史记录进行快速检索，帮助高效定位所需内容。
- **搜索结果高亮** — 自动突出显示搜索结果中的匹配文本，提升内容查找效率。
- **历史记录管理** — 支持删除、置顶和收藏历史记录，灵活管理常用内容。
- **标签管理** — 支持创建、编辑和自定义标签，通过标签对历史记录进行分类整理。
- **多选与批量操作** — 支持批量选择历史记录，并批量取消置顶、取消收藏或移除标签。
- **浮窗模式** — 提供紧凑的浮动界面，可快速访问剪贴板历史记录，并支持在鼠标附近唤出。
- **窗口状态同步** — 主窗口与浮窗之间同步历史记录的标签、置顶和收藏状态。
- **拖动复制** — 在浮窗模式下，可将文本拖动至兼容的外部应用程序，实现便捷的文本传递。
- **全局快捷键** — 通过全局键盘快捷键快速唤出浮窗，提升操作效率。
- **系统托盘运行** — 支持最小化至系统托盘，在后台持续提供剪贴板记录和快捷键唤醒功能。
- **中英文界面** — 支持简体中文和 English，可根据使用习惯切换界面语言。
- **深色与浅色主题** — 提供深色和浅色界面主题，适应不同使用环境。

## 安装说明

### 安装版

1. 从 [Releases 发布页面](../../releases) 下载 Windows 安装程序。
2. 运行安装程序。
3. 按照屏幕提示完成安装。
4. 启动 ClipAssist。

### 便携版

1. 从 [Releases 发布页面](../../releases) 下载便携版 ZIP 压缩包。
2. 将压缩包解压到任意文件夹。
3. 运行应用程序的可执行文件。
